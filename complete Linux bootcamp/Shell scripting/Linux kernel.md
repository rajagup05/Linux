
## Linux kernel

The Linux kernel is a free, open-source, Unix-like core software created by Linus Torvalds in 1991 that acts as the primary bridge between a computer's hardware and its operating system. It manages system resources like the CPU and memory, handles device drivers, and enforces system security.

- **Memory Management**: Allocates and frees RAM, managing virtual address spaces and paging.
- **Process Scheduler**: Controls CPU time sharing so multiple programs run smoothly at the same time.
- **Device Drivers**: Acts as a translator letting software talk to hardware like disks and USBs.
- **Virtual File System**: Provides a single unified way to read and write different file storage formats.
