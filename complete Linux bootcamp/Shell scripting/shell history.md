
## shell history

In Linux, the history command displays a list of previously executed commands in your terminal session. By default, this history is saved to a hidden file in your home directory, such as ~/.bash_history for Bash or ~/.zsh_history for Zsh.

### 🚀 Essential History Commands

- `history`: View your entire command history with line numbers.
- `history 10`: View only the last 10 commands.
- `history -c`: Clear the current session's history.
- `history -w`: Force-write current session history to the history file.
