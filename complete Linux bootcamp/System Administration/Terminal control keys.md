
## Terminal control keys

Linux terminal control keys manage running processes, navigate the command line, and edit text efficiently without using a mouse. The most essential control keys are Ctrl + C to terminate a hanging process, Ctrl + Z to pause a job, and Tab to auto-complete commands.

- `Ctrl + C`: Terminates the currently running foreground process immediately.
- `Ctrl + Z`: Suspends (pauses) the foreground process and moves it to the background.
- `Ctrl + D`: Closes the terminal session or sends an End-of-File (EOF) signal.

- `Ctrl + U`: Deletes all text from the cursor back to the start of the line.
- `Ctrl + A`: Jumps the cursor to the very beginning of the current line.

- `Tab`: Autocompletes folder names, file names, and shell commands.
